struttura completamente diversa. Prodotta con il verbo `redesign` della skill

```
python3 -m http.server --directory esempi/studio-commercialista-redesign 4174
```

## Che cosa è rimasto

Copy, claim, ordine delle sezioni, azione primaria, dati dello studio. Il verbo
`redesign` sostituisce il livello visivo, non il contenuto.

## Attenzione: contenuti fittizi

Come nell’originale: studio, indirizzo, partita IVA, numeri di iscrizione e
recapiti sono segnaposto (`00…`, `esempio.it`).
